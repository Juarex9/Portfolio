# FinTrack

> Gestor de finanzas personales

Llevar finanzas en hojas de cálculo dificulta ver patrones y cumplir metas de ahorro. FinTrack facilita el seguimiento y la planificación.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Prisma
- Vercel

## Features

- Seguimiento de gastos e ingresos
- Planes y metas de ahorro
- UI moderna con Next.js

## Getting started

```bash
git clone https://github.com/Juarex9/fintrack.git
cd fintrack
npm install
npx prisma migrate dev
npm run dev
```

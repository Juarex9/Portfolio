# Zafra

> IA agéntica para gestión y optimización del agro

Productores del NOA necesitan decisiones ágiles con datos dispersos entre ganadería, agricultura y clima. Zafra integra subagentes, datos satelitales, alertas y chat por Telegram.

## Portfolio (detalle del proyecto)

https://agustinjz.dev/proyectos/zafra

## Stack

- Python
- IA agéntica / subagentes
- Datos satelitales
- Telegram Bot API
- AgTech

## Features

- Arquitectura agéntica con subagentes para agricultura y ganadería
- Integración de datos satelitales
- Alertas configurables
- Asistencia conversacional por Telegram

# Ink | AI Risk Detector

> Detector de riesgos en Smart Contracts (Hackathon Aleph)

Interactuar con smart contracts sin evaluar riesgos expone a pérdidas evitables. Ink analiza direcciones y devuelve un score basado en criterios de riesgo evaluados con IA.

## Demo

- Live: https://ink-three-iota.vercel.app
- Portfolio: https://agustinjz.dev/proyectos

## Stack

- JavaScript / Node.js
- API REST
- IPFS (Pinata)
- MongoDB
- Blockchain & Web3

## Features

- Análisis de direcciones de smart contracts
- Scoring de riesgo con +10 criterios
- Integración IPFS para metadatos
- Demo pública post-hackathon

## Architecture

- Backend Node.js con motor de análisis
- Evaluación asistida por IA y reglas de scoring
- Almacenamiento y referencias en IPFS
- Frontend conectado a la API de análisis

## Getting started

```bash
git clone https://github.com/Juarex9/aleph-backend.git
cd aleph-backend
npm install
# Configurar variables de entorno (API keys, MongoDB, Pinata)
npm run dev
```

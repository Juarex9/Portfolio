# Leivy

> Análisis de subvenciones y grants — Sub0 Polkadot

Evaluar subvenciones en el ecosistema Polkadot es complejo sin herramientas centralizadas. Leivy ayuda a analizar grants y subsidios de proyectos en Polkadot.

## Demo

- Portfolio: https://agustinjz.dev/proyectos
- Repo: https://github.com/Juarex9/Sub0_data

## Stack

- React
- Node.js
- Polkadot
- API
- Blockchain & Web3

## Features

- Análisis de subvenciones y grants
- Desarrollado en hackathon Sub0 con SaltaDev
- Backend y frontend colaborativo

# Chat en Tiempo Real

> Mensajería instantánea con Socket.io

La mensajería en tiempo real requiere estado sincronizado y baja latencia. App con salas múltiples y autenticación.

## Demo

- Backend: https://backend1-coderhouse.onrender.com/

## Stack

- React
- Socket.io
- Node.js
- Express
- MongoDB

## Features

- Salas de chat
- Comunicación full-duplex
- Autenticación de usuarios

## Getting started

```bash
git clone https://github.com/Juarex9/chat-realtime.git
cd chat-realtime
npm install
npm run dev
```

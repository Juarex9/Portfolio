# VitisTrust

> Oráculo certificador de viñedos tokenizados

Los viñedos tokenizados necesitan certificación verificable de existencia y estado sanitario. VitisTrust monitorea parcelas vía satélite y emite certificación on-chain para validar viñedos tokenizados.

## Demo

- Live: https://vitistrust.vercel.app
- Portfolio: https://agustinjz.dev/proyectos

## Stack

- React
- Python
- Groq
- Hedera / Stellar
- Blockchain & Web3

## Features

- Monitoreo satelital de viñedos
- Validación de existencia y salud del cultivo
- Certificación para activos tokenizados
- Demo desplegada para hackathon VendimiaTech 2026

## Architecture

- Frontend en React para visualización y consulta
- Backend Python con análisis e integración Groq
- Capa blockchain (Hedera / Stellar) para certificación verificable
- Pipeline de datos satelitales hacia respuesta certificable

# Gestor de Turnos

> Sistema de gestión de turnos para cliente real

Los negocios necesitan coordinar turnos sin fricción entre personal y clientes. Sistema completo con calendario, recordatorios y panel de administración.

## Stack

- React
- Node.js
- MongoDB
- JWT
- API REST

## Features

- Gestión de turnos y calendario
- Recordatorios
- Panel admin
- Autenticación JWT

## Getting started

```bash
git clone https://github.com/Juarex9/gestor-turnos.git
cd gestor-turnos
# Instalar dependencias frontend y backend según estructura del repo
```
